## 3. Deviation Hunt
Image: panel-game.png
Image Links To: (leave empty)
Description:
Catch Once Human deviations right in Twitch chat!

* Type **!daily** to start (100 Starchrom + a Securement Unit, then 1 free unit every hour you play)
* When a deviation is spotted in the wild, type **!secure** (10 Starchrom a throw)
* **!pods** shows your collection, **!shop** / **!buy** for units and gloves
